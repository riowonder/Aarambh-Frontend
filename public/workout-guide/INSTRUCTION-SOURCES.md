# Exercise instruction sources

This guide combines exercise illustrations and instruction text from separate sources. An exercise detail page names the source of its instructions when steps are available.

- Everkinetic exercise instructions: https://github.com/everkinetic/data — CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/
- free-exercise-db instructions: https://github.com/yuhonas/free-exercise-db — Unlicense, https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md
- exercises-dataset instruction text: https://github.com/hasaneyldrm/exercises-dataset — MIT, copyright 2026 Hasan Emir Yıldırım. The MIT license text appears below.

No Gym visual images or GIFs from exercises-dataset are included in this guide.
